# Production Expansion v3.0 — Retired

This historical design has been superseded by the NFT V2 runtime.

Current production rules:

- Browser play produces score; it does not maintain a spendable browser currency.
- MATT Crystals are the reward-bearing resource and are settled through the NFT V2 flow.
- Miner power comes from NFT traits, equipped NFT gear, and temporary in-run choices.
- Pass chests award cosmetics only.
- All launch characters are available without a profile-currency purchase.

Use `README.md`, `docs/ADMIN_COMMAND_CENTER.md`, and the NFT V2 deployment documentation as the current source of truth.
